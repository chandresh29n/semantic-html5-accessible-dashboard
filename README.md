
# AccessBoard - Semantic HTML5 Accessible Dashboard

An enterprise-style dashboard demonstrating semantic HTML5 architecture, accessible UI components and WCAG 2.1 accessibility practices.

## Project Overview

AccessBoard is a responsive dashboard interface designed to demonstrate accessible web development techniques.

The project focuses on clean HTML structure, reusable components, keyboard navigation and accessible forms.

## Features

- Semantic HTML5 page architecture
- Responsive enterprise dashboard
- Accessible navigation and sidebar
- User management interface
- Structured enterprise data tables
- Accessible forms with validation
- Reusable modal dialog component
- Keyboard-friendly interactions
- Screen-reader-friendly labels and status messages
- Reduced-motion support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- WCAG 2.1 guidelines
- W3C HTML Validator

## Running the Project

1. Clone the repository.
2. Open the project in VS Code.
3. Start a local development server using Live Server.
4. Open the local website in your browser.
5. Navigate through the dashboard pages.

A local server is required because the modal component is loaded using JavaScript Fetch API.

## Accessibility Standards

The project follows accessibility practices inspired by WCAG 2.1 Level AA.

Testing includes:

- Keyboard navigation
- Semantic HTML structure
- Accessible form controls
- Focus visibility
- Screen-reader labels
- HTML validation
- Responsive design

## Validation

HTML markup should be checked using:

https://validator.w3.org/

Accessibility should also be evaluated using keyboard testing and appropriate accessibility testing tools.
